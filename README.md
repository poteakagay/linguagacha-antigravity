# 🍈 LinguaGacha 灵瓜小说精翻（反重力全局插件版）

> 基于上游开源项目 [`neavo/LinguaGacha (v0.141.2)`](https://github.com/neavo/LinguaGacha) 迁移适配的反重力（Antigravity）本地全局插件。
> 仅作个人本地运行与私有仓库（[`poteakagay/linguagacha-antigravity`](https://github.com/poteakagay/linguagacha-antigravity)）备份，不作公开二次分发。

---

## ✨ 这是什么？

安装并启用本插件后，你的反重力聊天助手就会化身 **LinguaGacha 原版傲娇翻译搭档**，自带全套小说精翻工作台：

- **不用敲任何命令、不用懂代码**：全程在聊天框里用大白话吩咐搭档就行。
- **保留排版的电子书直出**：直接吃进日文/英文 `.epub` 轻小说（自动剥离日文 `<ruby>` 振假名干扰、保留插图封面与目录、自动把日文竖排改为中文横排），翻译审校完直接导出**纯中文 `.epub`** 和**双语对照 `.epub`**。
- **全自动防翻车质检**：内置原版同款术语表扫描、译前/译后替换、特殊符号保护，以及 **6 类漏翻/假名残留/人名不统一/标点错配自动校对警告**。

## 🚀 日常翻小说：3 步傻瓜操作法

### 第 1 步：放好你的小说文件

在电脑任意位置新建一个文件夹（比如 `D:\小说\星灵骑士第1卷`），把要翻的小说放进去。
支持直接放入：`.epub`、`.txt`、`.md`、`.srt` / `.vtt` / `.ass` 字幕、`.json`。

### 第 2 步：打开反重力聊天框，复制一句话发给搭档

你可以在反重力里直接打开那个小说文件夹，或者直接在聊天里告诉搭档文件夹路径。下面 **4 条常用口令** 复制改一下路径就能直接用：

- **口令 1：导入小说 + 先扫一遍人名术语表（推荐新书第一步！）**
  > `搭档，帮我打开 D:\小说\星灵骑士第1卷 这个工程，把里面的小说导进来，先扫描提取一份角色名和专有名词术语表给我确认！`

- **口令 2：按「翻译并审校」全套标准精翻整本书并导出**
  > `搭档，按统一好的术语表把这本书精翻并审校一遍，修掉所有校对警告，最后帮我导出纯中文版和双语对照版！`

- **口令 3：只翻指定章节 / 先试翻第一章看看文风**
  > `搭档，先帮我试翻第 1 章，注意保留日轻的吐槽语气，翻完给我看看效果，先别翻后面的。`

- **口令 4：给已经翻好的书做二次校对捉虫**
  > `搭档，帮我检查当前工程里有没有漏翻的日文假名、译名不统一或者漏掉的引号，列出来帮我修干净，重新导出电子书。`

### 第 3 步：去文件夹里拿成品电子书

搭档忙完后，会在你的小说文件夹旁边自动生成两个成品文件夹：

- `你的书名_译文/`：干净清爽的纯中文译本（可直接传到手机、平板、Kindle 或阅读器看）
- `你的书名_双语对照/`：一段原文配一段中文的双语对照版（方便对照原文啃生肉或核对细节）

*(注：翻译过程中产生的术语表、记忆进度和自动存档都保存在该文件夹下的 `.lg_project` 和 `.lg_workspace` 里，下次接着翻第 2 卷时可以直接复用同一套人名术语表！)*

## ⚡ 两种翻译动力模式（按需自由切换）

### 模式 A：零配置免 Key 模式（默认开启，开箱即用）

- **怎么用**：什么都不用配！直接发消息让搭档翻。
- **原理**：直接调用你当前反重力聊天窗口正在使用的大模型逐组精翻 + 审校。
- **适合场景**：短中篇小说、单章试翻精修、提取角色术语表、润色校对捉虫。

### 模式 B：整本长篇高速并发模式（适合十几万字整卷轻小说）

如果你手头有一整卷十几万字的 `.epub` 想几分钟内一口气高速初翻完，再让反重力搭档做终审捉虫，可以填入外部 API 密钥解锁多线程并发引擎：

1. 找到模板文件：`D:\Antigravity\灵瓜迁移反重力\plugins\linguagacha\runtime\api_config.example.json`
2. 把它复制一份，改名为 **`api_config.json`**，放到你的**小说文件夹**里（或者直接放到 `D:\Antigravity\灵瓜迁移反重力\plugins\linguagacha\api_config.json` 全局生效）。
3. 用记事本打开 `api_config.json`，把 `"请填入你的API密钥"` 换成你自己的密钥（内置支持 **DeepSeek**、**Gemini**、**OpenAI 兼容接口** 以及本地 **SakuraLLM**）：

```json
{
  "active_profile": "deepseek",
  "profiles": {
    "deepseek": {
      "api_format": "openai",
      "base_url": "https://api.deepseek.com/v1",
      "api_key": "sk-在这里填入你的真实密钥",
      "model": "deepseek-chat",
      "concurrency": 6,
      "batch_size": 25
    }
  }
}
```

4. 保存后对搭档说：`搭档，用批量并发接口把整本书初翻完，然后你再帮我审校一遍导出！`

> 🔒 **隐私安全保护**：`api_config.json` 已被写入 `.gitignore` 黑名单，无论何时同步代码都**绝不会**被上传到 GitHub。

## 🎛️ 平时写代码时怎么暂时关掉傲娇搭档？

本插件已挂载为你的反重力全局插件。由于启用插件时会自动激活原版 LinguaGacha 的「傲娇萌妹翻译搭档」人设规则：

- **想关掉它恢复普通编程助手时**：在反重力聊天框输入 `/plugin`（或打开右上角设置里的 **Customizations / Plugins** 页面），找到 **LinguaGacha 灵瓜小说精翻**，点一下开关关闭即可，**无需重启立即生效**。
- **想翻小说时**：再去同一个开关点一下打开，你的专属翻译搭档就立刻回来啦！

本插件专注于**小说、电子书与纯文本类全链路精翻**。以下是与原版桌面端 `LinguaGacha v0.141.2` 的实装范围对照：

| :--- | :---: | :--- |
| 原版人设、系统提示词与任务宪章 | ✅ 100% 实装 | 原文完整迁入 `rules/AGENTS.md` 与 `agent-charter` |
| 22 个领域与格式技能包 + 内置脚本 | ✅ 100% 实装 | 含 `translation`、`glossary`、`text-preserve`、`writing-guide`、`epub` 等全部技能及 `.mjs` 脚本 |
| 预设规则库（`presets/`） | ✅ 100% 实装 | 完整保留全部译前替换、译后替换与文本保护预设 |
| Aho-Corasick 高速术语扫描与自动激活 | ✅ 100% 实装 | 毫秒级全书词频匹配、上下文自动挂载命中术语 |
| 6 类自动校对警告质检引擎 | ✅ 100% 实装 | 外文假名残留、术语未遵循、行数错配、首尾标点错配、原文高度相似（漏翻）、保护标签损坏 |
| `EPUB` 轻小说单语 & 双语引擎 | ✅ 100% 实装 | 自动清理 `<ruby>` 注音、保持封面插图与 NCX/Nav 目录、竖排 `vertical-rl` 自动转横排、标准无压缩 `mimetype` 封包 |
| `TXT` / `Markdown` / `JSON` / `SRT` / `.generic` | ✅ 100% 实装 | 支持单语导出、双语对照导出、同文去重自动联动（`DUPLICATED`） |
| 本地工程快照与事务安全工作区（MCP） | ✅ 100% 实装 | 同名提供 `workspace_open`、`workspace_run`、`workspace_apply`、`read_skill`、`batch_item_translation`、`batch_llm_request` |
