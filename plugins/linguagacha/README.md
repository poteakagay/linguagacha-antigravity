# 🍈 LinguaGacha 灵瓜小说精翻

欢迎使用 **LinguaGacha 灵瓜小说精翻** 反重力插件（基于上游项目 [`neavo/LinguaGacha`](https://github.com/neavo/LinguaGacha) 迁移适配，仅供非商业用途）。开启本插件后，助手将自带全套轻小说与文本精翻工作台，一条龙完成**术语提取、试译定调、整书并发精翻、单轮小包逐句精校、6 类机械警告清零及纯中文/双语电子书导出**。

---

## 🚀 3 步开始翻小说

1. **放好小说**：将待翻译的 `.epub`、`.txt`、`.md`、`.srt` 或 `.json` 放进电脑任意文件夹（例如 `D:\小说\第一卷`）。
2. **在聊天框发话**（把路径改成您的文件夹）：
   - **第一步提术语**：`帮我打开 D:\小说\第一卷，把里面的小说导进来，先提取一份人名和专有名词术语表给我确认。`
   - **可选抽样定文风**：`随机抽 100 条切片试译给我看看文风，先不写入工程。`
   - **整书精翻审校导出**：`按术语表把整本书翻译并审校一遍，修掉所有校对警告，最后导出纯中文版和双语对照版 EPUB。`
3. **拿成品看书**：完成后前往该文件夹下的 `书名_译文/` 和 `书名_双语对照/` 即可获取电子书成品。

---

## ⚡ 两种翻译模式

- **免配置直接翻（默认）**：无需填写任何外部 API Key，直接调用当前反重力聊天窗口的大模型拆包翻译与小包逐句精校，开箱即用。
- **外部 API 高速并发初翻（可选）**：将插件目录下 `runtime/api_config.example.json` 复制为小说文件夹（或本插件目录）下的 `api_config.json`，填入 DeepSeek / Gemini / OpenAI / SakuraLLM 密钥，即可多线程高速初翻长篇小说，再交由反重力精校收尾。

---

## 💡 温馨提示

- **随时切换开关**：平时写代码时，直接在本插件页面顶部关掉开关即可立即恢复普通编程助手（无需重启）；需要翻小说时再点开即可。
- **自由更换人设**：默认对话人设为《BanG Dream!》丰川祥子（翻译正文严格保持客观中立），可在插件目录下的 `presets/agent/personality.md` 与 `rules/AGENTS.md` 中自由修改为您喜欢的角色风格。
- **支持范围**：完整支持 `EPUB`（自动剥离振假名、保留插图封面与目录、竖排自动转横排）、`TXT`、`Markdown`、`JSON`、`SRT/VTT/ASS` 字幕与 `.generic` 数据包。
