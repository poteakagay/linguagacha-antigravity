# 🍈 LinguaGacha 灵瓜小说精翻

欢迎使用 **LinguaGacha 灵瓜小说精翻** 反重力插件！开启本插件后，聊天助手会化身为你的专属傲娇翻译搭档，帮你一条龙完成轻小说与文本的**术语提取、上下文精翻、6 类错误自动审校、纯中文及双语电子书导出**。

---

## 🚀 3 步开始翻小说

1. **放好小说**：把要翻的 `.epub`、`.txt`、`.md`、`.srt` 或 `.json` 放进电脑任意文件夹（例如 `D:\小说\第一卷`）。
2. **发话给搭档**：直接在聊天框复制发送下面任意一句（把路径改成你的文件夹）：
   - `搭档，帮我打开 D:\小说\第一卷，把里面的小说导进来，先提取一份人名和专有名词术语表给我确认！`
   - `搭档，按术语表把这本书精翻并审校一遍，修掉所有校对警告，导出纯中文版和双语对照版 EPUB！`
3. **拿成品看书**：翻译完成后，去同一个文件夹下的 `书名_译文/` 和 `书名_双语对照/` 拿成品即可！

---

## ⚡ 两种翻译模式

- **免配置直接翻（默认）**：无需填写任何 API Key，直接用当前反重力聊天窗口的大模型精翻与校对，开箱即用。
- **整本书高速并发初翻（可选）**：将插件目录下 `runtime/api_config.example.json` 复制为小说文件夹（或本插件目录）下的 `api_config.json`，填入 DeepSeek / Gemini / OpenAI / SakuraLLM 密钥，即可一键多线程高速初翻整卷长篇小说，再由反重力搭档终审修刺。

---

## 💡 温馨提示

- **随时切换身份**：平时写代码不想用傲娇搭档语气时，直接在本插件页面顶部的开关把插件关掉即可（无需重启，立即恢复普通编程助手）；要翻小说时再点开就行。
- **支持范围**：100% 支持 `EPUB`（自动剥离日文振假名、保留插图封面与目录、竖排自动转横排）、`TXT`、`Markdown`、`JSON`、`SRT/VTT/ASS` 字幕与 `.generic` 数据包；不含游戏二进制解包、PDF 原生重绘与本地语音识别。
